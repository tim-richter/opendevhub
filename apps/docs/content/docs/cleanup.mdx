---
title: Cleanup
description: Remove merged branches with their worktrees, and containers and images opendevhub no longer needs.
---

**Cleanup** in the sidebar scans every project and lists what can go, with the reason:

- **Branches & worktrees.** Local branches merged into their base (the base recorded when opendevhub
  created the branch, else the remote's default branch), checked. Branches whose upstream was deleted on
  the remote, which is what a squash merge on GitHub or Forgejo leaves, unchecked: "gone" can also mean
  deleted without merging. A branch's worktree and the worktree's own container go with it. A worktree
  with uncommitted changes is listed unchecked, with a warning.
- **Containers** opendevhub labelled but no longer tracks: a task container without its record, or a
  container of a project you removed. Running ones are unchecked.
- **Images**: old base images left by changes to a project's devcontainer config, images of removed
  projects, and the per-container UID images of removed task containers. Images built in the last 15
  minutes are never listed.

The scan runs `git fetch --prune` in each running project first. A project that isn't running is shown
with a Start button; its branches need its container to be scanned.

Nothing is removed until you press **Clean up selected** and confirm. Each item is checked again just
before it's removed, so something that changed since the scan (new commits, new uncommitted changes, a
container that started using an image) is skipped. Branches are only ever deleted locally.
